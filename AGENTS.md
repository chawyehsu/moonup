# Moonup

## Agent-generated documentation

Docs generated by or for agents are stored under `.agents/`, not `docs/`.

- `.agents/adr/` — Architecture Decision Records, sequential numbering (`0001-slug.md`), written via the `domain-modeling`/`grill-with-docs` skills.
- `.agents/handoff/` — handoff documents, named after the issue they address (e.g. `issue-195-atomic-toolchain-change.md`).

User-facing docs stay in `docs/`.
